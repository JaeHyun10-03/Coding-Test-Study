├── Phase1_구현-시뮬레이션/

## 사용법

1. SWEA 문제 페이지에서 입력/출력 예제 다운로드 → `input.txt`, `output.txt`에 붙여넣기
2. `Solution.java` 풀이
3. 실행 + 채점

```bash
./run.sh 1954     # 어디서든 문제 번호로 실행
../../run.sh      # 문제 폴더 안에서 실행
```

- `PASS` / `FAIL`(diff 표시) / `런타임 에러` 출력
- `Solution.java`는 SWEA 기본 제공 코드 그대로 (시험 환경과 동일)
- 표준입력을 `input.txt`로 리다이렉트하므로 `//System.setIn(...)` 주석은 풀 필요 없음 → 주석 상태 그대로 제출
- IntelliJ 사용 시: Run Configuration → Modify options → **Redirect input from** → `input.txt` 지정
- 표시 시간은 JVM 기동·컴파일 포함이라 실제 채점 시간보다 훨씬 김. 참고만

새 문제 추가:

```bash
./new.sh Phase1_구현-시뮬레이션 1873 상호의배틀필드 D3
```

순서 번호는 해당 폴더 마지막 번호 + 1로 자동 부여.
